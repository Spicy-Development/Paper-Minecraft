# Paper Minecraft
A small, browser-based 2D block-building game.

## Play

Open `index.html` in a modern browser. No install or server is required.

- Move with `A`/`D` or the arrow keys; jump with `Space`.
- Left-click to mine nearby blocks and right-click to place the selected block.
- Select a hotbar slot with `1`–`5` and open your backpack with `E`.
- Craft planks, sticks, and a stone pickaxe in the backpack. A pickaxe is needed to mine stone.
- Your world and inventory save automatically in this browser. Use the save button to save immediately.
